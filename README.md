# 西游降妖录

一款西游记题材的 2D 横版动作闯关小游戏，浏览器直接运行，零依赖。

5 名角色（悟空 / 八戒 / 唐僧 / 沙僧 / 白龙马）、15 个可升级技能、12 件法宝、九件可锻造装备、金币商店、12 关（8 主线 + 4 支线）三套主题立绘背景、**12 只各不相同的首领**，小怪和首领都会普攻 + 技能，起手有预警、能躲能打断。

五个人物是**逐像素画**的（不是矢量缩小、也不是贴图）：同一张像素图在游戏里、选角卡上、大立绘上按倍数放大，放大多少倍都不糊。做法见下面的「角色是一格一格画出来的像素」。

## 直接玩

不用装任何东西：

1. 点页面右上角绿色 `Code` → `Download ZIP`
2. 解压
3. 双击 **`西游降妖录.html`**

单文件，所有代码和美术都在里面，断网也能玩。

## 操作

| 按键 | 作用 |
| --- | --- |
| `A` `D` | 左右移动（连按两次触发奔跑） |
| `W` | 跳跃 / 空中再按一次二段跳 |
| `S` | 下蹲 |
| `J` | 普通攻击（连按走四段连招，五个角色各有一套动作，见下节） |
| `K` `U` `I` | 技能 1 / 2 / 3（每个角色各不相同） |
| `B` | 背包 |
| `L` 或 `C` | 锻造坊（材料换兵器 / 护甲 / 佩饰） |
| `G` | 属性商店（金币买属性） |
| `H` | 技能参悟（仙玉升技能） |
| `P` / `Esc` | 暂停 |
| `M` | 音乐与音效开关（会记住偏好） |
| `Enter` | 开始游戏 / 确认菜单 |

方向键与 `WASD` 等效。选角页可以直接用鼠标点卡片出战，结算页也能直接点选项；上次出战过的角色会被默认高亮。

选关页同样支持鼠标点卡片（锁着的关点了会提示差哪一关），方向键只在已解锁的格子之间移动。关卡前情页按 `Esc` 可以退回选关页换一关。

## 三种货币，各管一摊

| 货币 | 从哪来 | 花在哪 |
| --- | --- | --- |
| **金币** | 每只小怪都给 | `G` 属性商店：攻击 / 气血 / 防御 / 暴击 / 身法，越买越贵 |
| **仙玉** | 首领、过关奖励 | `H` 技能参悟：每个技能 5 重，每重 +10% 威力、-5.5% 冷却、+6% 范围 |
| **材料** | 打怪掉落 | `L` 锻造坊：九件装备分凡 / 灵 / 神三档，高阶还要搭金币 |

**成长**：每升一级自动 +22 气血、+4 攻击、+2 防御、+0.4% 暴击、+1.2 身法，并回满血。商店买到的属性、技能重数、等级都会存进本地存档，换关换角色都还在。

## 过关不是直接跳下一关

**每关都要把首领打掉才算过**（12 关，一关一只，没有例外）。打掉之后会先停在**过关结算**：

- 本关战果（击杀数、仙玉、金币、等级、用时）+ 这一关的后话
- 六个岔路：**下一关 / 关卡选择 / 属性商店 / 锻造坊 / 技能参悟 / 返回主菜单**
- 「下一关」只跳**主线**：支线要自己从关卡选择里回头补
- 从这些界面按 `Esc` 会回到结算页，而不是回到已经打完的关卡

## 怪物也会出招

以前小怪只会贴上来扣血，现在**每只怪都有普攻 + 技能**，一套「起手 → 出手 → 收招 → 冷却」的状态机在跑：

- **起手有预警**：脚下地面浮出一条贴地的光圈，从正上方顺时针扫一圈——扫满就出手。小怪头顶同时跳一个「!」徽标；首领个头太大，改用屏幕上方血条闪红代替
- **招式分五种**：近身（`melee`，判定框只在那一下有效）、弹道（`shot`，带重力和飞行时间，能走位躲）、冲撞（`dash`，先在地上铺一条虚线道，撞上只结算一次）、范围（`aoe`，以自身为中心的圆）、召唤（`summon`，场上活怪超过 14 只就停手）
- **杂兵各有一套**：小鬼「抓挠 + 掷石」、狼妖「撕咬 + 扑击」、蜘蛛精「毒牙（附毒）+ 吐丝（减速）」
- **首领从六个公共招式里挑 3~4 个**（重击 / 横扫 / 冲撞 / 震地 / 妖火 / 召妖），配出各自的节奏，所以十二只打法不一样
- **半血狂暴**：首领血量掉到一半，起手时间 ×0.78、收招 ×0.85、冷却 ×0.72、移速 ×1.12，动作会明显变快
- **能打断**：暴击可以打断小怪的起手，把它打回收招；首领有霸体，打断不了，只能靠躲

遇上的时候屏幕上方浮出**首领血条**：名字 + 等级、渐变血条、四分之一刻度、半血狂暴线、称号；起手时外框闪红并提示「！震地 起手」。走到离首领 680 像素内才浮现，打死后停 0.9 秒再淡出。

## 声音

音乐和音效都是运行时用 WebAudio 合成的，没有任何音频文件，单文件版照样有声音。

- **每个界面一首曲子**：主菜单（天宫序曲）· 战斗（战鼓）· 商店（集市）· 锻造坊（铁砧）· 技能参悟（空灵）· 过关（凯歌）· 落败（下行）
- **音效**：挥棒、命中、暴击、挨打、起跳、二段跳、落地、冲刺、技能、法宝、拾取金币/仙玉、升级、购买、锻造、失败提示
- 浏览器要求先有一次按键或点击才能出声，所以第一次按 `Enter` 之后音乐才会起来
- `M` 一键静音，偏好写进 `localStorage`

## 挨打有动作

角色被打中会进入 320ms 的受击姿态：身体后仰、手臂后甩、头比躯干慢半拍、眯眼张嘴，脚下踉跄撑开；小怪被打中会白闪 + 后仰一顿。

## 普攻四式（五个角色五套）

连按 `J` 循环出四招。每招由**两套曲线**拼出来：`attackMotion()` 管身体（重心、弓步、低头），`swingProfile()` 管兵器（手臂角 + 兵器绝对角 + 握点）。曲线表在 `art.js`（`BODIES` 9 种身体语言 / `PATHS` 20 种兵器轨迹），招式表在 `data.js` 的 `XY.BASIC_COMBO`——每式写明用哪两条曲线，所以五个人打起来是五种身法，不是同一套动作换皮。

| 角色 | 一式 | 二式 | 三式 | 四式 |
| --- | --- | --- | --- | --- |
| **悟空**·金箍棒 | 劈：抡到脑后，一整条圆弧劈到身前地面 | 戳：斜举后手往前一送，平捅到底 | 挑：棒梢点地，一路撩到头顶 | 甩：甩到背后（画在躯干后）再抡一圈横抽，能扫到身后 |
| **八戒**·九齿钉耙 | 筑：举过头顶，整个身子压下去 | 搂：耙子探出去，人往后坐往回拽 | 撞：耙子收进怀里，全靠肩和肚子撞 | 抡：原地转一圈，耙子带着人扫 |
| **唐僧**·空手 | 推掌：双掌从胸前平推出去 | 拂袖：袖子横向甩开，另一只手跟着摆 | 侧踢：手往后一收让位，腿是主角 | 金刚掌：沉马步、低头，双掌往下按 |
| **沙僧**·降妖宝杖 | 铲：杖头杵到身前地上，贴着地往前推 | 扫：人沉下去，杖贴地横扫 | 顶：杖身斜向脑后，棒尾朝前顶，扎得最远 | 压顶：举到最高再砸下来，蹲得最深 |
| **白龙马**·龙枪 | 刺：枪尖走平，距离最远 | 撩：枪尖从下往上撩到头顶 | 压杆：竖枪一挡，顺挡势斜着送出去 | 回马枪：回身往背后扎，人也跟着后撤 |

刀光、伤害判定、震屏、顿帧都压在各自的 `strike`（出招 42%~60%）那一帧才结算——兵器没到，伤害不落。刀光形状也按招式变：斜弧、拉长的白线加箭头、上撩弧加一串上升碎光、宽横扇。空手的三招刀光会贴着手走（`fxDx/fxDy` 单独标）。

想单独看某一招：`index.html?scene=play&char=0..4&atk=0..3&atkp=0.5`（`char` 选角色，`atk` 选第几段，`atkp` 定格在动作的哪个进度）。

调试首领和出招还有几个参数：`?lv=0..11` 直接进某一关、`?px=2020` 把人传送到指定的 x、`?sim=40&freeze=1` 空跑若干帧再定格（配合 `right=0` 让角色站住不动）、`?bosshp=0.3` 把首领血量压到三成看狂暴态。`sim` 跑完会把当前局面写进页面底部的调试条（含每只怪的状态与招式）。

## 角色是一格一格画出来的像素

五个角色不是矢量图缩小，也不是贴图，是**在内存里逐像素点出来的**：写一块 `Uint32Array` 缓冲，一行一行填色，再整块贴到画布上放大（`imageSmoothingEnabled = false`，所以放大多少倍都不会糊）。核心几件东西都在 `src/art.js` 的像素层：

| 东西 | 干什么 |
| --- | --- |
| `Painter` | 一块 w×h 的像素缓冲，带 `dot / rect / disc / capsule / poly / outline` 六支笔 |
| `poly()` | 扫描线多边形填充：逐行求交点再填，边缘必然是硬像素，不会出半透明 |
| `capsule()` | 线段 + 半径判距，四肢和棍身都靠它 |
| **垫墨底**（`UND = 0.55`） | 每个部件先画一圈大一号的墨色再填色。四肢压在躯干上时全靠这圈墨线分得开——这是像素角色的筋骨，不是描边特效 |
| `outline()` | 最后统一描边：只给"空像素紧贴实心像素"的位置上色，不往里吃 |
| `PX_LOOK` | 五人的造型表：身高、躯干粗细、头围、四肢长度，加一整套色板（衣/皮/甲/靴/披风……） |
| `HEADS` + `HEAD_PAL` | 头是**字符网格**设计的（10 行 × 9 列，`.` 透空），因为圆头 + 程序化五官在这个尺寸下永远读不出来 |
| `pxRig()` | 把动作状态（站立/跑/跳/冲刺/受击/出招/施法）换算成各关节角度，和矢量层共用同一套手感曲线 |

几个定死的规矩，改的时候别破坏：

- **`PX_UNIT = 1.74`**：一个美术像素 = 1.74 个世界单位。游戏里（1.15 倍）、选角卡（1.55 倍）、大立绘（3.15 倍）都是同一张像素图放大，倍率只影响每个像素多大。
- **眼睛做成 2px 宽 × 1px 高**。1px 的眼睛横向排两行会糊成一条黑槽，读不出"在看"；九格宽的脸，眼落在第 2~3 和第 5~6 格，中间留一格放鼻/嘴，左右才对称。
- **衣服必须和皮肤换一个色系**，只差明度不算。像素小、又垫了墨底压暗，暖褐袍配暖褐皮会糊成一整块肉色——八戒第一版就是这么翻车的，改成藏青才立起来。
- 兵器画两遍是有意的：`weaponBehind`（甩、回马枪这类反手蓄力）在躯干**之前**画一次，其余在躯干**之后**画一次。

想强制走回老的矢量画法：给 `pose` 加一个 `vector: true`。过场 CG 剪影就是这么干的——3.15 倍下像素块会大到糊成一坨，剪影要的是轮廓而不是颗粒。调试时也可以直接在控制台敲 `XY.Art.pixelMode = false` 全局切回矢量。

## 改代码

需要先装 [Node.js](https://nodejs.org/) 18 或更高版本。游戏本身零依赖，不用 `npm install`。

```bash
git clone https://github.com/HBUTFAKER/-.git xiyou
cd xiyou

node server.js                 # 本地起服务，浏览器打开 http://localhost:8080
node build.js                  # 把 src/ 打包成单文件 西游降妖录.html
node --test tests/*.test.js    # 跑测试，125 项全过才算没改坏
```

**重要**：改完 `src/` 里任意文件后，必须重新执行 `node build.js`，否则 `西游降妖录.html` 还是旧的。想边改边看，直接双击 `index.html` 也行（它引用 `src/` 下的源文件，不走打包）。

## 目录结构

```
src/data.js       角色、技能、法宝、怪物、关卡配置（改数值先看这里）
src/logic.js      纯函数逻辑：伤害、掉落、成长、商店定价、技能换算、锻造
src/audio.js      WebAudio 合成：七首循环曲 + 二十多种音效，无音频文件
src/engine.js     游戏主循环、物理、碰撞、角色动作状态机
src/art.js        角色美术：像素栅格层（人物）+ 矢量层（怪物/场景道具/兜底）
src/fx.js         特效层：刀光、火花、冲击环、巨棒、祥云
src/scenery.js    三套主题背景立绘与视差（按关卡的 theme 取）
src/ui.js         HUD、背包、商店、技能、锻造、过关结算、菜单
src/game.js       状态机与场景调度，串起上面所有模块
build.js          单文件打包脚本
server.js         本地预览用的小服务
tests/            Node 原生测试，覆盖核心逻辑、成长系统与渲染安全
```

## 想加东西，从哪里下手

- **加角色**：`src/data.js` 的 `CHARACTERS` 加配置 → `src/art.js` 的 `PX_LOOK` 加一行造型与色板 → `HEADS` / `HEAD_PAL` 画一张十行的脸
- **加技能**：`src/data.js` 的 `SKILLS`，`kind` 支持 `melee` / `dash` / `aoe` / `projectile`，`anim` 决定演出
- **改数值**（伤害、血量、冷却）：只动 `src/data.js`，不用碰引擎
- **加怪物 / 关卡**：`src/data.js` 的 `ENEMIES` 与 `LEVELS`，背景在 `src/scenery.js`
- **改怪物招式**：杂兵在 `XY.ENEMY_MOVES`，首领在 `XY.BOSS_MOVES`（六个公共招式）和 `XY.BOSSES[*].moves`（挑哪几个）；一套招式写 `type / range / windup / active / recover / cd / tell` 就够，引擎不用动
- **调手感**：`src/engine.js` 顶部的重力、跳跃初速、奔跑倍率等常量
- **调成长曲线**：`src/data.js` 的 `GROWTH`（每级成长）、`SHOP`（商店属性与涨价系数）、`SKILL_JADE_COST`（技能升级价）
- **加装备**：`src/data.js` 的 `ITEMS` 加一条（`slot` 决定部位，`tier` 决定品阶）→ `RECIPES` 配材料与金币
- **改音乐 / 加曲子**：`src/audio.js` 顶部的 `TRACKS`，`bpm` + 32 步的 `drums` / `bass` / `lead` 数组；新界面在 `game.js` 的 `musicScene()` 里指过去
- **加音效**：`src/audio.js` 的 `SFX` 里加一个函数，再用 `XY.Audio.sfx('名字')` 调

脚本加载顺序是 `data → logic → audio → art → fx → scenery → engine → ui → game`，`index.html` 和 `build.js` 里各有一份，新增模块时两处都要加。
